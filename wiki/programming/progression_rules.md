# Progression Rules

## Purpose

Guide how training stress is added.

## Core Rules

- Increase one major stressor at a time.
- Add frequency before very long single runs.
- Add easy volume before intensity.
- Add strides before intervals.
- Add hills or fartlek before VO2max.
- Add race specificity only after base is stable.
- Deload every three to five weeks or when fatigue signs accumulate.

## When To Use

- Build-phase planning.
- Deciding what to add next.

## When Not To Use

- During illness, injury return, or unstable recovery.

## Common Mistakes

- Adding volume, elevation, long-run duration, and quality together.
- Using the 10% rule as the only guardrail.
- Progressing because one workout went well.

## Coach Decision Rules

- If the runner is under four hours per week, keep progression simple.
- If fatigue signs appear, hold or deload before progressing.
- Do not overfit to one strong or weak workout.

## Evidence Notes

- Gradual load management: Coaching consensus.
- Exact safe progression rate: Limited evidence.
