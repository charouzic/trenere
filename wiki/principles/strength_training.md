# Strength Training

## Purpose

Support running durability and economy without compromising key running work.

## Core Rules

- Minimum effective dose: 1-2 sessions per week, 25-40 minutes.
- Include squat or lunge, hinge, calf/soleus, hip stability, and trunk/core.
- Use heavier strength in base or off-season.
- Use maintenance strength during race-specific phases.
- Add plyometrics only after a strength base.
- Trail runners need eccentric quad and calf work for descents.

## When To Use

- During base building.
- For runners with durability gaps.
- As maintenance during race-specific blocks.

## When Not To Use

- As a hard new stimulus during peak race-specific load.
- When soreness from lifting disrupts key running.

## Common Mistakes

- Treating strength as extra punishment.
- Starting heavy lifting too close to a race.
- Removing strength completely instead of reducing sets or load.

## Coach Decision Rules

- Place strength away from key sessions when possible.
- If lifting soreness disrupts running, reduce sets/load first.
- Strength supports running; it does not replace appropriate load management.

## Evidence Notes

- Strength can improve running economy: Moderate evidence.
- Strength prevents all injuries: unsupported overclaim.
