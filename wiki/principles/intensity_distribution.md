# Intensity Distribution

## Purpose

Keep hard training effective without letting moderate stress leak into every
week.

## Core Rules

- Default to 75-90% easy and 10-25% moderate/hard.
- Beginners should be almost entirely easy.
- Most recreational runners should have one hard session per week.
- Two hard sessions per week require stable sleep, recovery, and injury status.
- Hard sessions include threshold, tempo, VO2max, hill repeats, race pace, fast
  long-run finishes, and demanding trail long runs.
- Easy days must be truly easy.
- During high-stress weeks, reduce intensity before volume.

## When To Use

- Weekly review.
- Planning quality sessions.
- Deciding whether a long run counts as a hard day.

## When Not To Use

- As a rigid 80/20 law.
- When illness, injury, or major fatigue requires rest instead.

## Common Mistakes

- Counting gray-zone running as easy.
- Adding a second workout because the first felt good.
- Making long runs hard by terrain or elevation without counting them as hard.

## Coach Decision Rules

- If easy runs feel hard for multiple days, deload.
- If a runner misses quality, do not cram it later.
- If the week has a demanding trail long run, avoid stacking another hard
  session unless recovery is excellent.

## Evidence Notes

- Mostly easy distribution: Moderate evidence.
- Exact easy/hard ratio: Limited evidence.
- Polarized and pyramidal models: useful frameworks, not universal rules.
