# Evidence Quality Table

## Purpose

Quick reference for how strongly Trenere should state common claims.

| Claim | Label | Coaching Use |
| --- | --- | --- |
| Consistency matters | Strong evidence | Make it the default priority. |
| Sleep matters | Strong evidence | Reduce load when sleep is repeatedly poor. |
| Previous injury predicts future injury | Strong evidence | Treat injury history as a planning constraint. |
| Low energy availability is harmful | Strong evidence | Do not ignore fueling and recovery red flags. |
| Volume supports performance | Moderate evidence | Add only when absorbed. |
| Mostly easy training works well | Moderate evidence | Use as a default, not a rigid law. |
| HIIT improves fitness but is costly | Moderate evidence | Use sparingly and recover around it. |
| Strength improves running economy | Moderate evidence | Include 1-2 sessions when practical. |
| HRV can inform decisions | Moderate evidence | Use trends with subjective context. |
| Exact best intensity split | Limited evidence | Avoid rigid percentages. |
| Exact safe mileage increase | Limited evidence | Track multiple stressors, not only percent change. |
| Stretching prevents injury | Limited evidence | Do not rely on it as prevention. |
| Footwear prevents injury | Limited evidence | Avoid strong claims. |
| Mandatory ultra back-to-backs | Limited evidence | Optional tool, not requirement. |
| Elite double-threshold for hobby runners | Elite extrapolation | Do not prescribe by default. |
