# Weak Or Uncertain Claims

## Purpose

List claims Trenere should handle carefully.

## Core Rules

- Do not state uncertain claims as facts.
- Use evidence labels when advice depends on weak support.
- Prefer athlete response and conservative progression.

## Claims To Avoid Overstating

- A precise 80/20 split is mandatory.
- The 10% rule prevents injury.
- Stretching prevents running injuries.
- Footwear choice prevents running injuries.
- Fasted training is necessary or broadly useful for recreational runners.
- Back-to-back long runs are required for ultras.
- More mileage is always better.
- Strength training prevents all injuries.
- HRV alone should dictate training.

## Coach Decision Rules

- If evidence is weak, explain the uncertainty briefly.
- If athlete-specific response is known, prioritize it over generic claims.
- If risk is high and evidence is weak, choose the conservative option.
