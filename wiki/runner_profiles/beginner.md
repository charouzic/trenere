# Beginner Runner

## Purpose

Default rules for runners building habit, durability, and basic aerobic base.

## Core Rules

- 2-4 runs per week.
- Mostly easy running or run-walk.
- No formal intervals at first.
- Optional strides only after consistency is established.
- Long run: 30-75 minutes.

## When To Use

- New runners.
- Returning runners with low recent consistency.
- Runners below stable three-day frequency.

## When Not To Use

- As a cap for experienced runners with stable volume and recovery.

## Common Mistakes

- Adding intervals before habit is stable.
- Expanding the long run too quickly.
- Measuring success only by pace.

## Coach Decision Rules

- Prioritize consistency over structured workouts.
- Add days before adding demanding sessions.
- Use run-walk when needed.

## Evidence Notes

- Consistency and gradual load: Strong coaching consensus.
