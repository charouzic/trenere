# 5K

## Purpose

Prepare a recreational runner for a short road race without overusing hard
intervals.

## Core Rules

- Keep easy volume consistent.
- Use strides before formal intervals if speed exposure is limited.
- Use one quality session per week for most hobby runners.
- Add VO2max work only when base and recovery are stable.

## When To Use

- 5K goal race.
- Short speed-focused block after a base period.

## When Not To Use

- During injury return.
- When the runner is still building basic consistency.

## Common Mistakes

- Racing every workout.
- Adding VO2max before easy volume and strides are stable.
- Ignoring recovery because the race is short.

## Coach Decision Rules

- Beginner: consistency, easy running, optional strides.
- Intermediate: threshold or fartlek first, then short VO2max blocks.
- Serious hobby runner: one or two quality sessions only if recovery is stable.

## Evidence Notes

- HIIT improves fitness but is costly: Moderate evidence.
