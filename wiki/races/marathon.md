# Marathon

## Purpose

Prepare the runner for durable aerobic work, fueling, pacing, and load
management.

## Core Rules

- Build consistent easy volume before aggressive workouts.
- Long runs are high-load sessions.
- Practice fueling, hydration, gear, and pacing.
- Avoid large jumps in long-run duration.
- Do not stack marathon-specific work on poor recovery.

## When To Use

- Marathon goal race.
- Runners with enough base to tolerate long-run progression.

## When Not To Use

- When weekly consistency is not established.
- During active niggles or non-functional fatigue.

## Common Mistakes

- Making the long run too large a share of weekly load.
- Adding marathon-pace work too early.
- Treating more mileage as always better.
- Skipping fueling practice.

## Coach Decision Rules

- Add frequency and easy volume before very long single runs.
- Keep race-specific long sessions for stable blocks.
- If recovery is poor, shorten or simplify the long run before forcing it.

## Evidence Notes

- Volume supports performance when absorbed: Moderate evidence.
- Exact safe mileage increase: Limited evidence.
