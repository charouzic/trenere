# Trail Race

## Purpose

Prepare for terrain, elevation, descending, footing, fueling, and race-day
logistics.

## Core Rules

- Track time-on-feet and elevation, not only distance.
- Train climbing and descending gradually.
- Practice technical terrain when relevant.
- Fuel and gear practice matter.
- Downhill exposure is load.

## When To Use

- Trail races shorter than ultra distance.
- Road runners moving to trail terrain.

## When Not To Use

- When downhill load aggravates pain.
- When basic running consistency is unstable.

## Common Mistakes

- Comparing trail pace to road pace.
- Ignoring descending.
- Adding elevation and long-run duration at the same time.
- Treating hiking as failure.

## Coach Decision Rules

- Use terrain specificity instead of extreme mileage when time is limited.
- Count hilly long runs as hard sessions.
- Practice race gear before race day.
