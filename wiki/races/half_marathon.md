# Half Marathon

## Purpose

Build endurance and controlled sustained effort for recreational half-marathon
performance.

## Core Rules

- Support the race with consistent easy volume.
- Use threshold work more often than VO2max.
- Long runs matter, but avoid large jumps.
- Practice fueling if runs approach or exceed 90 minutes.

## When To Use

- Half-marathon goal race.
- Runners with stable weekly frequency.

## When Not To Use

- When the athlete cannot yet recover from normal long runs.
- During active injury return.

## Common Mistakes

- Racing long runs.
- Adding race-pace blocks before base is stable.
- Ignoring fueling practice.

## Coach Decision Rules

- Keep most long runs easy.
- Add race-specific blocks only closer to race day.
- If fatigue rises, preserve frequency and remove intensity.

## Evidence Notes

- Volume and mostly easy training: Moderate evidence.
- Exact race-specific workout timing: Coaching consensus.
