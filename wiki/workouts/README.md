# Workouts

Workout entries are stored by month as `wiki/workouts/YYYY-MM.md`.

For V1, keep entries simple and robust. Capture available facts and mark missing
fields as `not provided`, `unknown`, or `estimated`.

## Entry Format

```md
## YYYY-MM-DD — [Session name]

**Type:** Easy / Long run / Threshold / Ride / Swim / Strength / Race / Unknown
**Distance:** X km
**Duration:** HH:MM:SS
**Elevation:** Xm
**Avg HR:** XXX
**Avg pace:** X:XX/km
**RPE:** X/10 or not provided

### Notes

[Subjective feel, terrain, issues, context.]

### Morning metrics

HRV: X or not provided
Resting HR: X or not provided
Sleep: Xh or not provided

**Tags:** #easy #road #controlled
```

## Suggested Tags
