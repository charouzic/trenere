# Progression Runs

## Purpose

Practice controlled effort changes without turning the session into a race.

## Core Rules

- Start easy.
- Finish moderately faster only if the athlete is moving well.
- Keep the final segment controlled.
- Count hard progression runs as quality.

## When To Use

- For runners who need pacing discipline.
- As a lighter alternative to formal tempo when recovery is stable.

## When Not To Use

- When easy running is not currently easy.
- During niggle return or high-stress weeks.

## Common Mistakes

- Starting too fast.
- Turning the finish into race effort.
- Adding progression to every long run.

## Coach Decision Rules

- Use effort caps rather than exact pace when fatigue, terrain, or weather vary.
- If the athlete cannot progress smoothly, keep the next similar run easy.

## Evidence Notes

- Progression runs are coaching consensus.
