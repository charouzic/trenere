# Trenere Log

Use this chronological format:

```md
## [YYYY-MM-DD] {type} | {title}

Short notes.
```

Allowed types: `onboard`, `import`, `review`, `plan`, `lint`, `insight`,
`sync`.

## [YYYY-MM-DD] onboard | Athlete data scaffold created

Created private athlete-data scaffold from the public Trenere template. Replace
this entry when initializing a real athlete repo.
