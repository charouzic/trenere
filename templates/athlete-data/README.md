# Trenere Athlete Data Template

Copy this template into a private or local-only athlete-data repository.

Default local layout:

```text
~/trenere/               public Trenere core
~/trenere-athlete-data/  private athlete data
```

This data repo may contain profile details, injury notes, training logs,
COROS-derived data, raw imports, plans, reviews, and other personal coaching
memory. Do not push it as public.
